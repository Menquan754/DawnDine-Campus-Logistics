资产设备台账与盘点

一、资产编号与建档
1. 一物一码：资产编号建议采用“校区-类别-年份-流水号”，全校内唯一。
2. 新购资产验收后 3 个工作日内建档，做到采购、验收、入账、贴签同步。
3. 台账字段：资产编号、名称、类别、规格型号、地点、责任人、状态、购置日期、
   保修期、供应商、原值、备注、照片。
4. 资产状态统一为“在用 / 闲置 / 维修中 / 报废”，变更时及时更新。
5. 标签脱落或模糊的，盘点时补打，不得出现无标签资产。

二、领用、调拨与借出
1. 领用登记领用人、部门、用途、日期，贵重设备需部门负责人审批。
2. 跨楼栋调拨同步修改存放地点与责任人，避免账实不符。
3. 借出资产登记借出时间、预计归还时间与联系人，逾期催还。
4. 教师离职、岗位调整时办理资产交接，交接单双方签字。
5. 学生借用设备由教师担保，明确损坏赔偿与归还责任。

三、盘点
1. 每学期至少全面盘点一次，贵重与易移动资产每季度抽盘。
2. 盘点前冻结调拨，导出台账逐件核对编号、地点与状态。
3. 盘盈资产查明来源后补录；盘亏资产查明去向，无法说明的按学校规定处理。
4. 盘点结果形成报告：应盘数、实盘数、盘盈、盘亏、账实相符率。
5. 账实相符率目标不低于 98%，差异逐项说明整改措施与完成时间。

四、维保与巡检
1. 电梯、锅炉、消防设施、燃气设备、二次供水等按法规由有资质单位定期维保，
   留存合同、维保记录与检测报告。
2. 空调、饮水机、投影、多媒体等按厂家周期保养，滤网与滤芯按时更换。
3. 设备巡检记录运行状态、异响、温度、渗漏与安全附件有效性。
4. 保修期内优先走厂家售后，留存报修单与更换配件记录。
5. 超期服役设备评估安全风险，必要时提前报废。

五、报废与处置
1. 报废条件：达到使用年限、损坏无法修复、维修成本过高、安全不达标。
2. 报废流程：使用部门申请—技术鉴定—资产管理员审核—校领导审批—处置—销账。
3. 报废设备移出前清除数据与个人信息，涉密存储介质按保密要求销毁。
4. 报废资产统一处置，不得私自变卖、赠送或留用。
5. 处置收入按学校财务制度入账，处置记录与照片归档。

六、数据质量与检查
1. 每月抽查台账 10% 的记录，重点核对地点、责任人与状态。
2. 发现资产长期闲置，提出调剂或处置建议，提高使用效率。
3. 台账导出前核对字段完整性，缺项标注“待补”并限期补全。
4. 资产数据与采购、财务、维修工单定期对账，避免重复或漏记。
